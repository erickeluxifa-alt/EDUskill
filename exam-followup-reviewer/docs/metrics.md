# 统计口径说明（docs）

本文档给出 `followup_reviewer.py` 所有核心口径的数学定义，与代码实现一一对应，供教研审核与复现。

## 1. 班级整体画像

```
画像分 score = 0.5 × 得分率(p_overall) + 0.3 × 及格率(pass_rate) + 0.2 × (1 − 低分率(low_rate))
画像档位 band_final：
  score ≥ 0.85            -> 优秀
  score ≥ 0.72            -> 良好
  score ≥ 0.60            -> 中等
  score ≥ 0.48            -> 待提升
  其余                    -> 需重点改进
```

- 人数 = n_present；均分 = totals.mean；及格率/优秀率/低分率均来自 totals（百分比化显示）
- 信度 α = totals.alpha（None 时显示 `-`，不参与画像分）

## 2. 知识点掌握度

每个知识点聚合所有题目得分：

```
kp得分率 = Σ(该 kp 各题均分) / Σ(该 kp 各题满分)
```

| 得分率 | 掌握度档位 |
|---|---|
| ≥ 80% | 已掌握 |
| ≥ 60% | 掌握一般 |
| ≥ 40% | 薄弱 |
| < 40% | 严重薄弱 |
| 无数据 | 数据不足 |

**共性薄弱**：参与对比的班级 ≥2，且这些班级该知识点得分率均 < 60%（单班时该知识点按班内情况处理）。

## 3. 题目四象限与回流建议

对每题（单班或多班分别）：

```
p = 题目得分率（题均分/满分，取自 questions[].p）
d = 区分度（questions[].d）

双低·疑议题: p < 0.5 且 d < 0.2
高区分·拉分题: p < 0.5 且 d ≥ 0.3
送分·低效题:   p ≥ 0.8 且 d < 0.2
正常:          其余
```

回流建议（按知识点平均分）：

| 知识点得分率 | suggest |
|---|---|
| < 0.4 | 下调难度 |
| < 0.6 | 控制难度 |
| ≥ 0.8 | 可加码 |
| 其余 | 维持 |

疑题清单（双低 + 高区分拉分题）写入 blueprint_feedback.json 的 `question_review`，带班级归属。

## 4. 学生帮扶名单

```python
# 按总分降序 ranking
pos = (名次) / 总人数        # 名次位置：越排前越小
尾部25% 标记: pos > 0.75     # 名次靠后 25%
尾部预警:     students[].tier 为预警/高危
百分位低:    pct ≤ 25        # 超越率（成績高于该比例同学）
percentile 显示 = (总人数 − 名次) / 总人数 × 100   # 第1名 ~ 94.7%，末尾 0%
```

- 名单按总分降序排列，输出到 `help_list.csv`（UTF-8-BOM）
- `students` 为空时跳过该节，报告内给出提示

## 5. 安全与确定性

- 全标准库；HTML esc()（& < > " '）→ XSS 防护
- Markdown 单元格 cv()：控制字符剥离 + `& < > |` 实体/转义
- CSV csv_safe()：公式注入前缀 `'`（= + - @ 开头）
- 确定性：同输入 → 同输出（followup_summary.json 可做 hash 校验）
