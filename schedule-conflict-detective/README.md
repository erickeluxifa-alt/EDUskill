# 课程表冲突检测与调课推荐 (schedule-conflict-detective)

> **版本**: v1.0.0 · **作者**: ht · **更新日期**: 2026-08-17

## 适用角色与场景
- 教务处管理员、院系教学秘书、教学副院长助理。
- 学期初排课后批量体检；中途调课时引入新冲突的核对；
  多院系联合排课合并后的交叉检查。

## 行业属性 & 可复用范围
- 高等教育 / 职业教育教务管理通用场景，可迁移至中小学排课、考场编排、会议室预订等多资源调度类任务。

## 核心增益
1. 三维资源(教师×教室×班级)同时段冲突自动检测——避免人工肉眼比对遗漏;
2. 自动周次聚合压缩（如 [3..8] 显示为 "3-8"）大幅减少重复条目噪音;
3. 调课建议带"全维安全"过滤：候选节次保证移动后不产生新冲突，
   而非仅当前教室空闲这种片面判断;
4. 零依赖纯标准库实现，离线可用、无外部 API Key 暴露风险;
5. 用户可控字段全量 HTML 实体转义 + 字段长度截断防 XSS/注入。

## 输入输出
- 输入: JSON 排课数据文件路径 (`examples/sample_with_conflicts.json` 为参考样例)
- 输出:
    * Markdown 报告打印到 stdout （含校验失败清单 + 冲突详细清单 +
      可执行调课建议 + 单日连排高负荷预警）
    * 追加 `--json` 参数后额外打印结构化 JSON 结果供下游系统消费

## 触发方式
```bash
python3 scripts/schedule_analyze.py <path-to-schedule.json> [--json]
```

或通过自然语言触发："帮我检查这学期课表有没有冲突" /
"分析这份课表的冲突并给调课建议 schedule.json" 等。

## 配置项
- `DEFAULT_PERIOD_POOL`: 默认每日节次池 `[1..12]`,可在脚本中调整适配不同作息制度;
- `TEACHER_DAILY_OVERLOAD`: 单人单日连排预警阈值=8节,可在脚本中按校情修改;
- `MAX_FIELD_LEN`: 用户可控字段最大字符数=200,防止异常输入撑爆报告.

## 示例运行结果片段
```
> 共 5 条有效 | 无效 0 条 | 冲突 2 条
**分类统计**: `教室冲突=1`, `教师冲突=1`
| 类型         | 课程A↔课程B        | 教师 | 教室   | 时间段      | 周次 |
|-------------|-------------------|------|--------|------------|------|
| 教师冲突    | 高等数学A ↔ 概率论| 张明 |        | 周一 第2节 | 3-8  |
| 教室冲突    | 高等数学A ↔ 数据结构|    | 教1-101| 周一 第1节 | 1-6  |

## 三. 调课建议
1. 将「概率论」从周一第2节 → 周一第4节 (理由: 全维安全)
2. 将「数据结构」从周一第1节 → 周一第3节 (理由: 全维安全)
```

## 已知限制
- 不感知法定节假日和校历特殊安排，所有时间均按公历处理;
- 教师/教室/班级任一字段为空时跳过对应维度检测;
- 复杂度 O(n²),n > 5000 时建议分批切片执行;
