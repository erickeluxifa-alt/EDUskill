# 课堂座位编排与约束核验

- 目标角色：教师、班主任、监考教师、教务人员
- 教育属性：课堂组织、考试组织、学生支持
- 触发：排座位、生成考试座位表、避开指定同学、前排安排、检查座位冲突
- 输入：JSON 学生名单、教室行列、禁用座位、固定座位、前排学生和分离约束
- 输出：Markdown 可打印预览 + JSON 结构化结果
- 依赖：Python 3 标准库，无网络、无第三方包
- 核心增益：把人工排座经验转为可解释的约束求解和冲突复核
- 限制：默认只处理二维规则，不能推断医学/纪律原因，不能自动提交教务系统

## 快速开始

```bash
python3 scripts/plan_seats.py --demo
python3 scripts/plan_seats.py --input examples/sample_input.json --out-dir output
```

`--json` 仅打印结构化结果；`--strict` 在存在数据错误或未满足约束时以非零状态退出。所有结果都是预览，座位执行需人工确认。
