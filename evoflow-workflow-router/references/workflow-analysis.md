# Workflow: Data Analysis

面向业务数据的全链路分析工作流，覆盖数据理解、质量评估、模式发现、报告输出。

## 分析目标

每次数据分析任务须覆盖：
1. **理解数据**：明确数据来源、业务含义、时间范围
2. **评估质量**：识别缺失值、重复、异常、格式不一致
3. **发现模式**：统计探索、趋势、相关性、异常
4. **设计流程**：基于实际问题的可复现清洗与转换方案
5. **输出结论**：业务语言表达，数据为证

## 执行约束

- **不修改原始数据**：清洗前告知用户并说明原因
- **不过度假设字段含义**：列名不清时先问用户
- **不忽略数据质量问题**：异常必须明确标记
- **不偏离用户目标**：分析深度和方向锚定用户问题

## 数据质量分级处理

| 级别 | 情形 | 处理方式 |
|------|------|----------|
| 阻断级 | 关键列全空、主键大面积重复 | 停止并告知用户，等待确认后再继续 |
| 决策级 | 高缺失率、模糊离群值 | 展示各处理方案的利弊，让用户选择 |
| 轻微级 | 零散格式不一致、首尾空白 | 直接处理，在报告中记录 |

## 执行步骤

### 1. 理解业务背景
在读数据前先明确：
- 业务场景是什么？
- 用户想解决什么问题？
- 哪些字段最重要？

### 2. 文件读取（防溢出）
```bash
wc -l <file>
```
行数 > 500 时禁止全量读取，改用分批读取或 grep 精准定位。

文件路径：`/mnt/user-data/uploads/` → 输出到 `/mnt/user-data/outputs/`
编码：优先 utf-8，失败则 latin-1 / cp1252

### 3. 基础探索
```python
import matplotlib
matplotlib.rcParams['font.sans-serif'] = ['DejaVu Sans']

# CSV 输出 Excel 兼容
df.to_csv(output_path, encoding='utf-8-sig', index=False)
```

### 4. 结论表达
不只输出统计数字，要解释业务含义：
- ❌ `均值 3200`
- ✅ `平均客单价约 3200 元，但中位数仅 1800 元，说明少量高价值订单拉高了均值`

## 输出报告格式

```markdown
## 数据分析报告

### 数据概览
（数据集规模、来源、时间范围、关键字段说明）

### 数据质量
（发现的问题、严重程度、已执行操作 / 待确认事项）

### 关键发现
（3~5 条最重要洞察，每条附数据支撑）

### 处理流程
（对数据做了哪些转换、为什么这么做）

### 建议
（数据改进方向、后续深入分析方向）
```

## 典型场景参考

**电商订单**：先确认时间范围 → 检查 Amount 列负值（退款？）→ 按支付状态定义"有效订单" → 时序趋势 + 品类/城市拆解

**问卷/调研数据**：优先暴露结构问题（多 Sheet、列名不一致、空行）→ 向用户确认后再清洗合并

**清洗交付任务**：输出处理日志，说明每步操作及原因，格式见：
```
数据处理日志
源文件: xxx.csv (N 行 × M 列)
输出文件: xxx_cleaned.csv (N' 行 × M' 列)

变更：
1. 删除重复行: 删除 X 条完全重复记录
2. 丢弃"备注2"列: 缺失率 96%，无有效信息
...
```
