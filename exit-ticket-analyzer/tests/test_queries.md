# 自测 Query 清单

本轻量 Skill 以一个离线分析入口为核心，缩减为 20 条 Query，覆盖正常、同义、组合、缺失、边界、异常与副作用预览分支。预期结果均为生成报告或返回明确错误，不写回外部系统。
