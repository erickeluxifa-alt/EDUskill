# 实验室预约防冲突排程器（lab-reservation-scheduler）v1.0.0

> 面向实验室管理员/实验员/教务干事的零依赖离线排程工具：输入实验室资源与预约申请，
> 自动生成无冲突的预约排程表、人工协调缺口清单与资源利用率统计。

## 适用角色与场景

| 角色 | 典型任务 |
|---|---|
| 实验室管理员/实验员 | 新学期实验课排课、开放预约批次录入、加开/调课后重排 |
| 教务处教学秘书 | 实验教学工作量核对、机房排课冲突检查 |
| 院系教务干事 | 提交预约申请、核对排程结果 |

## 依赖与运行环境

- **唯一依赖**：Python 3.6+（标准库 `json/argparse/html/re`），无任何第三方包，离线可运行
- 无需网络、无需数据库、无需配置文件

## 安装与触发方式

```bash
# 方式一：文件输入
python3 scripts/lab_reservation_scheduler.py examples/sample_lab.json

# 方式二：stdin 管道
cat examples/sample_lab.json | python3 scripts/lab_reservation_scheduler.py --json

# 方式三：结果写盘（默认只读预览）
python3 scripts/lab_reservation_scheduler.py examples/sample_lab.json --out plan.json

# 方式四：自测（29 用例）
bash scripts/run_selftest.sh
```

## 输入规范

顶层结构：`resources`（必填）、`requests`（必填）、`bookings`（可选）、`rules`（可选）。
中英文字段别名均支持：

| 对象 | 支持的键（任一即识别） |
|---|---|
| 资源 | `id/name/名称/名字` · `type/类型/类别/类别名` · `capacity/容量/人数/座位数/工位数` · `equipment/设备/设备清单` · `open_dates/开放日期/可用日期` |
| 申请 | `id/name/名称/实验` · `course/课程/实验课程/实验名称` · `group/班级/学院/专业班级` · `students/人数/学生数/预约人数` · `teacher/教师/授课教师/负责人` · `date/日期/开课日期/预约日期` · `slots/时段/时间/periods` · `res_type/资源类型/需要类型` · `equipment/设备/所需设备` · `split/拆分/可拆分` · `priority/优先级` |
| 已排定 | `id/name/名称` · `date/日期` · `slot/时段` · `resource/资源/实验室` · `students/人数` · `teacher/教师` |

顶层容器别名：`resources`≈`实验室`≈`资源`；`requests`≈`预约申请`≈`预约`≈`applications`。

日期支持 `2026-09-09`、`2026/9/9`、`2026年9月9日`；时段支持名称（`08:00-10:00`）、序号（`1`~`5`）或起始时间（`08:10` -> 自动匹配）。

## rules 可配置项（均有默认值）

| 键 | 默认 | 说明 |
|---|---|---|
| `split` | `true` | 允许跨资源/跨时段拆分 |
| `teacher_conflict` | `true` | 同一教师同一天同一时段至多一处 |
| `capacity_strict` | `true` | 人数超容量即缺口；`false` 时超载仍可排入但记为"需确认" |
| `max_per_resource_slot` | `1` | 同一资源同一时段最多预约单数（独占） |
| `open_slots` | 内置 5 段 | 自定义时段列表，如 `["09:00-12:00","15:00-17:00"]` |

## 自测与质量

`bash scripts/run_selftest.sh`：29 条用例 -> PASS=29 FAIL=0（100%），覆盖：
常规流程、中英文别名、三种日期形态、教师互斥开关、缺输入（6 类）、边界（精确容量/拆分开关/超大班级/自定义时段/优先级排序/资源开放日/设备/类型不匹配）、异常数据（0 人/负人/非列表/坏 JSON/空资源）与 XSS 注入防护。详见 [SELF_TEST.md](./SELF_TEST.md)。

## 已知限制

1. 贪心算法局部最优，非全局最优（可与人工微调结果对比后复跑）；无甘特图/Excel 导出；
2. 未接入真实实验室管理系统/教务系统，均为 JSON 模拟数据；
3. 时段为离散槽位，不支持分钟级自由时段；多校区/跨楼宇距离未建模；
4. 需求不可解决时输出缺口与建议，需人工决策后调整输入复跑。
