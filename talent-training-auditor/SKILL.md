# 人才培养方案智能审核助手

专为高校、职业院校教务管理人员设计的人才培养方案审核工具，支持**政策合规审核**与**版本对比分析**两大核心功能。

---

## 功能一：政策合规审核

### 工作流程

1. **确认方案文件**
   - 支持格式：`.docx`、`.pdf`、`.txt`、纯文本粘贴
   - 若用户提供了附件路径，直接读取；若是粘贴文本，直接处理

2. **获取政策要求**
   优先级从高到低：
   - 用户直接输入的政策条款（最高优先级）
   - 用户上传的政策文件
   - 内置通用政策框架（见 `references/policy_frameworks.md`）

3. **结构化解析方案**
   调用 `scripts/parse_plan.py` 解析方案，提取以下模块：
   - 专业基本信息（专业名称、代码、学制、学位类型）
   - 培养目标与毕业要求
   - 课程体系结构（必修/选修/实践比例）
   - 学分学时分配
   - 实践教学环节
   - 师资与条件要求
   - 质量保障机制

4. **逐项合规检测**
   调用 `scripts/compliance_check.py`，对照政策逐项检测，输出结构化问题清单

5. **生成审核报告**
   按 `references/audit_report_template.md` 格式输出，包含：
   - 问题汇总（按严重程度分级：必改 / 建议改 / 关注项）
   - 逐条问题说明（定位到具体章节 + 问题描述 + 政策依据 + 修改建议）
   - 合规评分（满分100分）

---

## 功能二：版本差异对比

### 工作流程

1. **确认两份方案文件**
   - 明确哪份是"旧版"（版本A），哪份是"新版"（版本B）
   - 若用户未说明，询问确认

2. **结构化解析两份方案**
   分别调用 `scripts/parse_plan.py` 解析，映射为可比较的章节树结构

3. **差异对比分析**
   调用 `scripts/diff_plans.py`，按以下维度对比：
   - **新增内容**：新版有、旧版无
   - **删除内容**：旧版有、新版无
   - **修改内容**：同一条款文字有变动
   - **结构调整**：章节顺序、编号变化
   - **数值变动**：学分、学时、比例等数字变化

4. **生成差异报告**
   按章节结构化输出，每处差异标注变动类型和影响评估

## 注意事项

- 政策合规审核结果仅供参考，最终以教务主管部门审定为准
- 如需加载特定省份/院校政策，请提供政策文件或在对话中说明政策要求
- 方案文件若为扫描PDF，需先通过 `pdf` Skill 进行OCR处理
