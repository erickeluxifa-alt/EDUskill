# 教学进度计划生成器 teaching-progress-planner v1.0.0

## 核心场景

每学期开学前，教师/教研组需把「课程大纲章节 + 学时」按校历（教学周、考试周、节假日）
编排成逐周教学进度表提交教务处。本工具把这一编排与检查自动化：

- 按章节顺序自动拆入每周（跨周标注「续」、同周可合并），节假日周、考试周自动跳过；
- 自动检查：章节学时合计 vs 课程总学时偏差、学时超出可授课周容量、计划提前结课；
- 一键产出 Markdown 周计划表、结构化 JSON、可导入 Excel 的 CSV。

## 目标角色

任课教师、教研组长、教学秘书（代排课）、教务处督导（进度合规抽查）。

## 教育行业属性与复用范围

- 通用「课程 × 校历 → 逐周计划」模式，适用于：高校本科/专科、中职技校、培训机构学期课；
- 同一结构可扩展用于：实验课学期排程、实训周安排、复习周安排。

## 核心增益

- **专家经验 SOP**：为「开学前教学进度表」这一高频文书的制作提供一键生成 + 三查（学时一致/容量充足/节奏合理）；
- **专业数据资产**：输出结构化 JSON 教学日历，可被其他系统（课表系统、LMS）直接消费；
- **评价/生成工具**：生成 + 检查一体，杜绝章节丢失、学时对不上总课时等开学常见错误。

## 输入输出

| 方向 | 内容 |
|------|------|
| 输入 | JSON（course/semester/units）或简化 TXT；详见 SKILL.md 字段表 |
| 输出 | `教学进度计划.md`（周计划表+检查提示）、`.json`（结构化）、`.csv`（Excel 可直接打开） |
| 交互 | 命令行退出码：0=无警告 1=有警告 2=输入错误；`--strict` 把警告升级为错误 |

## 使用示例

```bash
# 1) JSON 输入，输出三个文件到 out/ 目录
python3 scripts/planner.py -i examples/sample_input.json -o out

# 2) TXT 输入（粘贴习惯），只看成功与否
python3 scripts/planner.py -i examples/sample_input.txt -q

# 3) 标准输入（管道）
cat data.json | python3 scripts/planner.py -i - -o out

# 4) 严格模式：有警告（学时偏差/溢出）即返回退出码 2，便于 CI
python3 scripts/planner.py -i examples/sample_overflow.json --strict; echo $?
```

## 依赖与配置

- 零第三方依赖，仅 Python 3.6+ 标准库（csv / json / html / datetime / re / argparse）；
- 无需任何网络、Token、数据库；用户可控文本全部 HTML 转义 + CSV 公式注入防护。

## 验证结论（2026-08-24）

- 默认示例（sample_input.json）：退出码 0，56 学时 ×14 可授课周精确排布，节假日/考试周全跳过；
- 溢出样例（sample_overflow.json）：正确报容量不足并列出溢出学时；
- TXT 样例：配置行解析、单元行解析、警告与退出码正常；
- 20 条自测 Query 全部通过，详见 `测试记录/自测记录.md`。

## 限制

1. 周粒度排布，不细分星期几节次；`teaching_days` 字段仅占位；
2. 节假日按周处理，不处理调休换班（基于公历推算）；
3. 严格按章节顺序排布，不自动调整章节讲授顺序（如需调整顺序请先改输入）。
