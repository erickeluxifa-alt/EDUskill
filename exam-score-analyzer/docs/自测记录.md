## 三、修复记录（开发期发现并解决的问题）

1. **demo 运行 FileNotFoundError**：输出目录在生成 demo 数据前未创建 → 修复：`os.makedirs` 提前到 main 的 try 块开头。
2. **预警名单被截断**：`clean_md_cell` 默认 limit=200 导致长名单（17 人）被截断、HTML 报告缺人 → 修复：增大 limit 并移除「取前 15 人」限制，名单完整展示。
3. **HTML `<style>` 块嵌套不匹配**：样式输出与 `<head>` 包裹重复 → 修复为只输出 CSS 内容、单次包裹，验证标签配平 OK。
4. **CSV 公式注入防护缺失**：对 `= + - @` 及制表符开头的单元格补 `'` 前缀（含学生姓名、班级、考试名等用户可控文本）。
5. **不可见 Unicode 混入**：SKILL.md / 脚本尾部出现 U+E0100 变体选择符等不可见字符 → 按白名单清理（仅清 U+FE00–U+FE0F、U+E0100–U+E01EF，保留 \r\n\t），清理后 `py_compile` 通过、SKILL.md 结构完整。
