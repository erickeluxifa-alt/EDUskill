# 考后成绩分析助手（exam-score-analyzer v1.0.0）

## 场景定位
一线教师 / 年级组长 / 教务管理人员在每次考试（期中、期末、月考、周测）阅卷后，把「学生逐题得分明细」交给本工具，**几分钟内**获得：
班级总体统计、分数段分布、试卷质量指标（每题得分率、区分度、整卷信度）、知识点掌握度诊断、学生个体预警、讲评课建议与分层作业建议。

解决痛点：
1. 手工统计均分/及格率/分数段费时易错；
2. 缺少试卷质量指标（得分率、区分度、信度）支撑命题改进；
3. 讲评课「凭感觉」确定讲哪些题，缺乏数据依据；
4. 分层教学缺少量化抓手（哪些学生、哪些知识点需要补）。

## 输入
1. **试卷元信息 JSON**（`--meta`）：
```json
{
  "exam": "2026年秋 Python 期中考试", "course": "Python 程序设计基础",
  "date": "2026-08-26", "total_marks": 100, "className": "计科2401班",
  "questions": [
    {"id": "1", "marks": 8, "kp": "基础语法", "type": "单选", "difficulty": "易"}
  ],
  "pass_rate": 0.60, "excellent_rate": 0.85, "low_rate": 0.30, "group_fraction": 0.27
}
```
- `kp` = 知识点名称（同一知识点多题为空则自动归集）；`type`（题型）/`difficulty`（易/中/难）仅用于展示。
- 四个口径参数均可选，缺省即使用教育测量学常用阈值：及格线按 60%、优秀 85%、低分 30%、区分度分组取前/后 27%。

2. **学生逐题得分 CSV**（`--scores`）：
- 表头支持中英文别名：`student_id|sid|学号`、`name|姓名`、`class|班级`；
- 题目列支持 `Q1|q1|t1|题目1` 等（按出现顺序与 meta.questions 对应）；
- 缺考行=整行留空（自动判定）；某题未答=该单元格留空；
- 单元格**非数字 / 超过题面满分**时按缺失处理并在提示中说明（`--strict` 可改为失败退出）。

## 执行
```bash
python3 scripts/score_analyzer.py --demo                              # 内置示例数据全流程演示
python3 scripts/score_analyzer.py --meta m.json --scores s.csv    # 基本用法
python3 scripts/score_analyzer.py --meta m.json --scores s.csv --out-dir out/ --bins 10
python3 scripts/score_analyzer.py --meta m.json --scores s.csv --pass-rate 0.5 --excellent-rate 0.8
python3 scripts/score_analyzer.py --meta m.json --scores s.csv --strict --no-html
```

## 输出（--out-dir，默认 output/）
| 文件 | 用途 |
|---|---|
| analysis_report.md | 主报告：总体概况/分数段/试卷质量指标/知识点掌握度/学生画像/讲评建议/数据说明 |
| report.html | 自包含可视化报告（无外部依赖，桌面/移动端自适应，可打印存档） |
| class_summary.csv | 班级汇总指标（Excel 直开，UTF-8 BOM） |
| question_stats.csv | 每题统计（得分率、满分率、区分度、评价） |
| knowledge_stats.csv | 知识点掌握度（含薄弱标记） |
| students.csv | 学生总分/百分位/未答/薄弱知识点/预警 |
| analysis.json | 全量结构化结果（供二次处理或前端组件） |

退出码：0=成功（含告警）；2=输入错误（文件缺失/格式非法/统计口径冲突等）；1=内部异常。

## 统计口径（教育测量学常用约定）
- 得分率 P = 题平均分/题满分；P≥0.85 偏易、0.60–0.85 适中、0.40–0.60 偏难、<0.40 过难。
- 区分度 D = 高分组（总分前 27%）与低分组（后 27%）该题得分率之差；有效人数不足 6 人时返回“无数据”。
- 信度：Cronbach α = k/(k-1)·(1−Σσi²/σ总²)（只需逐题都答过的完整样本 ≥4 人；样本不足返回“未计算”）。
- 掌握度 = 知识点下各题实得分合计 /（满分合计×实考人数）；<60% 判定薄弱、≥80% 判定已掌握。

## 安全边界
- 零第三方依赖、纯标准库、离线计算、确定性输出（相同输入两次运行结果一致）。
- 无 shell/eval/网络调用；用户可控文本（考试名/课程/学生名/知识点）输出 HTML 转义并截断；
- CSV 输出对所有以 `= + - @` 或制表符开头的单元格加 `'` 前缀（防公式注入）；
- Markdown 表格单元格做竖线/控制字符清洗。

## 限制与适配
- 当前为独立本地计算器：成绩取自教务系统导出/手工整理的 CSV，未直接对接具体教务系统（适配层留作扩展点）；
- 只做统计与建议生成，不代替教师对教学内容的判断；讲评建议基于规则模板，可结合学科经验再加工；
- 主观题成绩仍需人工判给分（本工具不自动打分，打分交由 homework-grading-analyzer）；
- 样例数据 `examples/` 与 `--demo` 为确定性模拟，供验证与演示。

## 联动
- 上游：`exam-blueprint-generator`（细目表，含知识点/题型/难度）≈ 可直接复用 `kp/difficulty`；
- 上游：`exam-paper-assembler`（组卷）可直接为 meta 提供完整题目清单；
- 下游：预警名单/薄弱知识点可直接作为 `student-academic-warning` 预警与分层教学输入。
