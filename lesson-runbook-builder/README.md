# 课堂授课运行单生成器

这是一个面向教师与教研员的离线教育场景 Skill。它将课程目标或已有活动整理为可执行的课堂时间轴，适合课前 3-5 分钟快速生成初稿，也适合教研组复盘时比较不同课堂流程。

## 适用角色与范围

- 任课教师：课前准备课堂节奏、提问和检查点
- 班主任/辅导教师：组织主题班会或学习支持活动
- 教研员：检查课堂流程是否有可观察产出
- 可复用范围：中小学、高校、职业教育、企业培训中的单节课或单次活动

## 核心增益

- 把目标转成教师动作、学生动作和可观察产出
- 在时间轴中插入形成性检查，减少“讲完才发现没学会”
- 提供进度落后、无响应、资源不可用三类低风险预案
- 结构化 JSON 可被其他课程设计或课堂观察工具继续消费

## 依赖与限制

仅依赖 Python 3 标准库，不联网。不会连接 LMS/SIS，也不会发送、发布、改分或写回任何系统。生成内容是教学草案，须由教师按学科、班级、无障碍与学校制度复核。

## 交付物料

- `SKILL.md`：触发方式、输入输出与限制
- `scripts/build_runbook.py`：主入口
- `examples/sample_input.json`：模拟输入
- `tests/test_build_runbook.py`：最小回归测试
