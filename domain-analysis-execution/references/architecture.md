# 架构与知识加载规范

## 知识层

稳定知识按行业存放，包含经营框架、指标口径、分析维度和业务约束。动态知识按主题存放，主题内部按行业分段，包含阶段策略、关键事件和运营抓手。一次任务只读取目标行业及命中的动态主题。

## 方法路由

九类方法：异常检测、归因、趋势、预测、分层、漏斗、结构迁移、影响模拟、A/B 实验。

选择顺序：

1. 是否存在指标变化或异常。
2. 是否需要解释原因。
3. 是否需要判断趋势或预测未来。
4. 是否有明确的分组、漏斗、结构、干预或实验信号。

优先一个主方法，其他方法作为辅助方法，避免同时加载全部方法说明。

## 输出框架

- 监控：指标状态、异常、影响范围、处理建议。
- 诊断：结论、口径、原因拆解、不确定性、实操建议、验证方案。
- 预测：假设、预测结果、区间、风险、跟踪指标。
- 汇报：背景、关键发现、业务影响、决策请求、后续动作。
