# 教学班合并方案评估器

## 核心场景

院系在低选课人数、师资变化或教室调整时，需要比较多个并班方案，避免只看人数而遗漏学生课表冲突、教学进度、授课语言、校区与教师负荷。

## 目标角色

教务处、院系教学秘书、课程负责人。

## 教育行业属性与复用范围

适用于高校、职业院校及采用教学班制的培训机构。可复用于开课前小班整合、开学后低人数班级调整、师资临时收缩和教室资源优化。

## 核心增益

- 把并班核查 SOP 固化为可重复执行的离线规则。
- 同时检查六类约束并保留可解释原因。
- 以 JSON 接口衔接 SIS/LMS 导出快照或审批组件。
- 所有变更只生成预览，避免误操作真实教务数据。

## 触发示例

- “帮我评估这几个低选课教学班能不能合班。”
- “比较三个并班方案，检查容量和学生冲突。”
- “师资调整后哪些教学班适合合并？”

## 快速开始

```bash
python3 scripts/plan_consolidation.py \
  --input examples/sample_input.json \
  --output-dir /tmp/consolidation-output
```

输出：
- `consolidation_report.md`
- `consolidation_result.json`

## 输入输出

输入为教学班、匿名学生选课快照、学校阈值和人工给定候选组。完整字段见 `references/input-spec.md`。输出包含推荐/复核/阻断状态、评分、原因、影响学生数和确认清单。

## 依赖与配置

- Python 3.9+
- 仅使用标准库，无网络依赖。
- 通过输入中的 `policy` 设置最大进度差、跨校区策略和复核分数阈值。

## 验证

```bash
python3 tests/test_planner.py
```

测试覆盖默认流程、异常流程和边界输入。`tests/query_cases.json` 另含 25 条自然语言触发与流程自测用例。

## 交互与副作用边界

本能力只生成方案预览。涉及真实合班、退补选、教室调整、教师任务变更、通知发送时，必须由有权限人员在真实系统中复核并确认；本工具不提供执行入口，也不保存凭据。

## 数据安全

建议只输入匿名 ID。不要加入姓名、手机号、证件号、账号、密钥或连接串。所有文本按 JSON 数据读取，不执行命令，也不生成可执行 HTML。

## 已知限制

- 只识别完全相同的时间段字符串，不解析自然语言课表。
- 不自动生成候选组合，避免在政策不完整时给出不恰当方案。
- 不判断课程内容等价性、教师资质、合同规则或学校审批政策。
- 使用模拟数据完成验证，尚未接入真实 SIS/LMS。
