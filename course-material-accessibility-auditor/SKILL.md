# 课程材料无障碍审核

对结构化 JSON 课程材料执行确定性审核，输出问题清单、优先级和发布前人工确认预览。

## 使用流程
1. 收集 JSON 输入；字段规范见 `README.md`，示例见 `examples/sample_material.json`。
2. 运行：`python3 scripts/audit_material.py INPUT.json --out OUTPUT_DIR`。
3. 检查 `audit.json` 与 `report.md`；先处理阻断项，再处理高、中优先级问题。
4. 仅生成整改建议和发布预览，不自动改写原文、不上传 LMS、不发送通知。
5. 缺少输入时，列出必需字段并提供示例；格式错误时返回可定位错误，不猜测内容。

## 核心规则
- 标题应有且层级不跳级。
- 图片必须提供非空、非占位的替代文本；装饰图可标记 `decorative: true`。
- 链接文本不得使用“点击这里/更多”等脱离上下文无意义表达。
- 表格需有标题或说明，并标识表头。
- 过长句与过长段落标为可读性提醒，不替代专业判断。
- 检测明显手机号、邮箱，提示发布前核实；报告中只显示脱敏片段。

## 输出约定
- `audit.json`：机器可读结果、计数、规则命中和发布建议。
- `report.md`：教师可审核报告，包含阻断项、整改建议与确认清单。
- 退出码：0=完成且无阻断项；2=完成但存在阻断项；1=输入或执行错误。

## 安全与边界
输入仅作为数据解析，不执行用户文本，不拼接 shell 命令。所有路径由脚本安全创建；不访问网络。该工具提供发布前技术检查，不宣称完成法规合规认证，也不替代残障支持部门或人工可用性测试。
