# 家校沟通规则

## 推荐顺序

1. 说明沟通目的和预计范围。
2. 先呈现具体优势或积极进展。
3. 陈述带日期、来源和情境的可核实事实。
4. 用开放式问题核实背景，不猜测原因或动机。
5. 提供数量有限、可执行的支持选项。
6. 明确双方下一步、复核节点和需再次确认的信息。

## 措辞规则

- 说“记录显示两次未按时提交”，不说“总是不认真”。
- 说“想了解是否存在需要学校配合的情况”，不说“家里肯定没有管”。
- 优势与困难都应有事实依据；未知内容标记为待核实。
- 不输出医学或心理诊断，不贴人格、家庭、能力或纪律标签。

## 隐私与副作用

只保留沟通所需的最少信息；样例和测试使用化名。输出仅为预览，发送、提交、写回和批量修改必须在学校认可渠道中由授权人员人工完成。
