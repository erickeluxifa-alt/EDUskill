# 人工智能本科培养方案测试画像

本文件是根据用户提供的《人工智能 人才培养方案》提炼的测试画像，仅用于验证 Skill 的“培养方案对齐”能力。实际任务必须优先解析用户当次上传的正式材料。

## 基本信息

- 专业代码：080717T。
- 专业名称：人工智能（Artificial Intelligence）。
- 培养层次：普通本科。
- 基本学制：4 年，可在 3-6 年内完成学业。
- 学位与学分：工学学士，170 学分。
- 主干学科：人工智能。

## 培养定位摘要

培养具备数理和计算机软件基础、人工智能基本理论与专业知识，能够运用人工智能方法解决实际问题，从事智能信息处理、智能系统开发与应用，并具备工程实践、研究创新和项目管理发展潜力的应用型人才。

## 毕业要求主题

1. 工程知识。
2. 问题分析。
3. 设计/开发解决方案。
4. 研究。
5. 使用现代工具。
6. 工程与社会。
7. 环境和可持续发展。
8. 职业规范。
9. 个人和团队。
10. 沟通。
11. 项目管理。
12. 终身学习。

生成具体课程方案时，只映射该课程能够有效支撑的要求，不要求全部覆盖。

## 课程体系线索

- 自然学科基础：高等数学、大学物理、线性代数、离散数学、概率论与数理统计。
- 专业基础：计算机导论、数据结构、最优化理论与方法、高级语言程序设计、脑与认知科学基础、自动控制原理、算法分析与设计、数据库原理。
- 专业核心：人工智能导论、智能系统与控制、自然语言处理、机器学习、深度学习、模式识别、数字图像处理、大数据分析与挖掘。
- 专业选修：至少 16 学分，其中 Python 语言程序设计为必选课。
- 实习实践教学：36 学分，包含职业技能实践、专业实习、创新创业实践等环节。

## 测试时应验证

- 能否判断为高等教育本科模板，而非职业教育模板。
- 能否识别课程在“自然基础 / 专业基础 / 专业核心 / 专业选修 / 实践”中的位置。
- 能否将课程目标映射到部分毕业要求并给出评价证据。
- 能否同时处理理论、实验、项目和实践活动。
- 能否在缺少具体课程总课时时标记待确认，而不是擅自编造。
