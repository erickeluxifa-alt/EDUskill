# 分学段设计模板

仅选择与本次授课对象匹配的主模板。用户材料中的正式称谓优先于本文通用称谓。

## 基础教育

### 定位重点

- 以上位课程标准、学科核心素养、学业质量要求和教材单元为主要依据。
- 明确年级、学生已有经验、认知负荷、常见误解和跨学科连接。
- 目标强调概念理解、思维方法、实践探究、表达交流和价值观养成。
- 教学活动采用情境任务、观察实验、合作探究、练习反馈与迁移应用。
- 评价兼顾过程性与结果性；作业控制难度梯度和完成负担。

### 推荐字段

- 学科 / 学段 / 年级 / 教材版本 / 单元位置。
- 核心素养维度与学业质量要求。
- 单元大概念、关键问题、学习进阶和易错点。
- 基础、应用、探究三类任务。

### 避免事项

- 不套用“毕业要求指标点”“岗位能力”等高教或职教术语。
- 不默认课时长度、作业时长和考试权重；无材料时标记待确认。
- 不把素养目标写成口号，必须关联课堂行为或作品证据。

## 职业教育

### 定位重点

- 以专业教学标准、人才培养方案、职业标准、岗位任务和技能等级要求为主要依据。
- 明确专业、年级、培养层次、典型岗位、工作任务和实训条件。
- 课程目标按知识、技能、职业素养设计，突出“做中学”和理实一体。
- 教学内容按项目、任务或工作过程组织，体现安全规范、质量标准和职业伦理。
- 评价优先使用过程记录、操作考核、项目成果、企业标准或技能证书要求。

### 推荐字段

- 岗位群 / 典型工作任务 / 职业能力 / 课程任务。
- 实训设备、软件、耗材、场地、安全和师资条件。
- 项目成果物、操作规范、质量标准和评分量规。
- 理论与实践课时、校内实训与岗位实习衔接。

### 避免事项

- 不把职业教育方案写成纯理论目录。
- 不虚构企业标准、证书要求或实训条件。
- 没有安全规范和设备信息时，必须列为待确认项。

## 高等教育

### 定位重点

- 以人才培养目标、毕业要求、课程体系、课程大纲和教材为主要依据。
- 明确专业、培养层次、开课学期、先修课程、课程性质、学分与学时结构。
- 采用成果导向设计：毕业要求或能力指标点映射到课程目标、教学活动和评价证据。
- 教学内容兼顾理论体系、学术前沿、工程实践、研究方法、伦理责任和持续学习。
- 评价可包括考试、作业、实验、项目、报告、展示和同伴评价，并说明目标对应关系。

### 推荐字段

- 培养目标 / 毕业要求 / 指标点 / 课程目标映射。
- 先修与后续课程、课程体系位置、理论与实践比例。
- 复杂问题、实验研究、系统设计、工程伦理、团队协作等能力证据。
- 形成性与终结性评价的权重及达成度计算口径；无校方规定时不擅自给定权重。

### 避免事项

- 不把培养目标直接复制为课程目标，应拆成课程可承担、可评价的部分。
- 不承诺单门课程覆盖全部毕业要求。
- 不虚构学分、学时、考核比例或学校审批结论。

## 学段判断规则

1. 材料中出现小学、初中、高中、课程标准、学科核心素养时，优先判断为基础教育。
2. 材料中出现中职、高职、职业本科、岗位任务、技能等级、理实一体时，优先判断为职业教育。
3. 材料中出现学士、硕士、学分、毕业要求、专业认证时，优先判断为高等教育。
4. “本科”与“职业本科”不能混同；需结合学校类型、培养定位和课程组织判断。
5. 证据冲突时列出冲突项，请教师确认主模板。
