# 结构化教学方案生成

把教师提供的原始材料转换为与人才培养要求对齐、可继续编辑的教学方案。默认使用中文 Markdown 输出；用户指定 Word、表格或其他格式时，再调用对应文件处理能力生成。

## 参考资料加载顺序

按工作阶段渐进加载，禁止一次性读取全部参考资料：

- 识别学段后读取 `references/stage-templates.md`，只采用已识别学段对应的规则。
- 准备生成成品时读取 `references/output-schema.md`。
- 完成初稿后读取 `references/quality-checklist.md` 并执行自检。
- `references/ai-bachelor-sample-profile.md` 仅用于测试本 Skill，正常教学方案任务禁止加载，避免示例内容污染用户材料。

## 输入识别

将材料分为四类并列出文件名或标题：

1. **约束材料**：人才培养方案、课程标准、专业教学标准、学校模板、学时学分规定。
2. **内容材料**：教材、讲义、课件、参考书、案例、实验说明。
3. **任务要求**：课程名称、授课对象、总课时、班级基础、输出范围、格式偏好。
4. **补充依据**：行业标准、职业技能标准、考试要求、已有教案或题库。

如文件格式需要专门解析，先调用对应文件处理能力。不得仅凭文件名推断正文内容。

## 证据与优先级

事实冲突时按以下顺序处理：

1. 用户本轮明确要求。
2. 本校人才培养方案或学校正式模板。
3. 课程标准、专业教学标准或教学大纲。
4. 教材与教师提供的内容材料。
5. 通用教育经验。

为关键结论标记依据状态：

- `明确`：材料直接给出。
- `推断`：依据上下文合理推导，必须说明推断依据。
- `待确认`：材料不足或相互冲突，不能擅自补齐。

引用材料时使用教师可识别的文件名、章节或页码；不要暴露本地路径。若缺少课程名称、学段、授课对象或总课时等关键边界，先列出已识别内容，并只追问阻塞生成的最少问题。

## 工作流

### 1. 建立材料清单

输出“材料解析摘要”，说明材料类别、覆盖范围、版本信息和明显缺口。识别：

- 学段：基础教育 / 职业教育 / 高等教育。
- 授课对象：年级或学期、专业或方向、先修基础、典型学习特征。
- 课程性质：公共基础、专业基础、专业核心、专业拓展、实践、必修或选修等。
- 课程边界：总学时、理论/实践学时、学分、教学周、考核方式。

### 2. 解析培养要求

提取培养目标、毕业要求或核心素养、能力指标、课程体系位置、实践要求和考核要求。将原文要求拆成可教学、可评价的指标，不改变原意。

### 3. 建立对齐矩阵

建立“培养要求 → 课程目标 → 教学单元 → 学习活动 → 评价任务”的映射。每个课程目标至少对应一个教学单元和一个评价证据；不得出现无法评价的空泛目标。

教学目标使用三维结构：

- **知识目标**：学生应理解、解释、辨析或迁移的概念与原理。
- **能力目标**：学生应完成的操作、分析、设计、实践或解决问题任务。
- **素养目标**：责任意识、伦理规范、合作沟通、创新意识、审美、劳动或学科核心素养。

目标使用可观察动词，标注目标编号、达成标准、证据和所支撑的上位要求。

### 4. 选择学段模板

按 `references/stage-templates.md` 选择且仅选择一个主模板。材料显示跨学段或定位冲突时，先说明判断依据并请教师确认，不混用模板术语。

### 5. 生成结构化方案

严格按 `references/output-schema.md` 生成以下内容：

1. 课程与对象画像。
2. 依据与约束摘要。
3. 培养要求对齐矩阵。
4. 知识/能力/素养三维教学目标。
5. 课时总体安排。
6. 知识图谱。
7. 教学大纲。
8. 分课时教学计划。
9. 课后习题、参考答案与评价规则。
10. 待教师确认事项。

知识图谱同时提供 Mermaid 图和节点关系表。若当前载体不支持 Mermaid，保留节点关系表，不能只输出不可编辑图片。

### 6. 自检与修订

逐项执行 `references/quality-checklist.md`。发现以下问题必须先修订再交付：

- 总课时、理论/实践学时或学分不守恒。
- 目标没有上位要求依据或没有评价证据。
- 教学单元与教材、课程标准脱节。
- 习题超出已安排教学内容。
- 学段术语、难度或评价方式不匹配。
- 把推断写成确定事实。

### 7. 教师二次确认

结尾提供“教师确认清单”，只列真正需要决策的项目，包括：待确认项、当前建议、影响范围和可选修改。教师反馈后，保留已确认内容，仅修改受影响模块，并同步更新对齐矩阵、课时合计和习题映射。

## 输出原则

- 先给结构化成品，再给简短说明，不输出冗长推理过程。
- 表格中的目标、单元、活动、评价和习题使用稳定编号，便于教师二次编辑。
- 忠实于输入材料；无法确认的数据用 `待确认`，不得编造学校制度、课程标准或教材章节。
- 方案应能直接进入教研讨论，但不能声称已通过学校审批或替代教师专业判断。
