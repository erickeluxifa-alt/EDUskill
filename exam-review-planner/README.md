# 考后讲评备课助手（exam-review-planner）

面向一线教师、年级组长与教务管理人员的考后讲评课备课工具。把「逐题统计」一键变成「可以直接上课的方案」：**必讲/应讲/略讲分级 → 精讲时长分配 → 时间轴 → 变式建议 → A/B/C 分层辅导名单**，输出 Markdown 教案、自包含 HTML 课件与 CSV 名单（Excel 直开）。

与 exam-blueprint-generator、exam-paper-assembler、exam-score-analyzer 构成「命题→组卷→考试→分析→讲评」闭环，本工具是最后一环：直接消费上游 analysis.json。

## 快速上手

```bash
# 1. 全流程演示（内置 8 题 + 16 名学生）
python3 scripts/review_planner.py --demo --out-dir out/

# 2. 复用 exam-score-analyzer 的分析结果（推荐）
python3 scripts/review_planner.py --analysis ../exam-score-analyzer/analysis.json --session 45

# 3. 逐题统计 CSV + 成绩单（教务系统导出，拿来即用）
python3 scripts/review_planner.py --qstats qstats.csv --students roster.csv --exam 初二期中
```

## 输入

三选一（必填，互斥）：

| 参数 | 说明 |
|---|---|
| `--analysis PATH` | 直接复用 exam-score-analyzer 输出的 analysis.json |
| `--qstats PATH` | 逐题统计 CSV 或 JSON 数组（题号/知识点/满分/得分率/区分度/题型/题干） |
| `--demo` | 内置示例数据，跑通全流程 |

可选参数：

| 参数 | 说明 |
|---|---|
| `--students PATH` | 成绩单 CSV，优先级最高，覆盖内置名单 |
| `--exam / --course / --class-name / --date` | 元信息 |
| `--total-marks / --pass-rate / --excellent-rate / --low-rate` | 分层口径 |
| `--session 45` | 讲评课时长（分钟） |
| `--out-dir PATH` | 产物目录（默认 `out/`） |
| `--no-html / --no-md` | 裁剪对应产物 |
| `--quiet` | 安静模式（仅打印摘要） |

列名支持中英文别名、大小写不敏感（题号|id|qid、得分率|正确率|p、区分度|d、知识点|kp 等），缺列自动降级并告警——教务导出「拿来就能用」。

### 输入示例

**qstats.csv**（逐题统计）：

```csv
题号,知识点,满分,得分率,区分度,题型
1,基础语法,8,0.83,0.25,单选
5,函数与模块,15,0.54,0.31,编程
7,综合应用,16,0.40,0.37,综合
```

**students.csv**（成绩单）：

```csv
学号,姓名,班级,总分
S001,陈晨,初二3,88
S002,王强,初二3,60
```

## 输出

| 文件 | 用途 |
|---|---|
| `review_plan.md` | 讲评课教学方案：总体反馈/时间轴/核心题单/略讲清单/变式建议/分层名单/跟踪建议 |
| `review_deck.html` | 自包含讲评课件：无外部依赖、桌面/移动自适应、可打印 |
| `review_plan.json` | 全量结构化方案（供程序二次处理） |
| `question_cards.csv` | 每题决策卡片（分类/讲法/精讲时长/变式建议） |
| `tier_students.csv` | A/B/C 分层辅导名单（含总分与建议任务） |

退出码：`0`=成功（含告警）、`2`=输入错误、`1`=内部异常。

## 分级与时长口径

- 得分率 `P`：**P<50% 必讲**（精讲），50%≤P<85% **应讲**（精讲），P≥85% **略讲**（小组自查+口头点易错）；
- 讲法：区分度 `D≥0.3` 按「讲思路」，否则「全班统一讲概念」；
- 精讲时长：按紧迫度 `0.6×(1−P)+0.4×D` 分配总预算，单题上限 7 分钟；
- 时间轴：时长≥15 分钟为 6 阶段（阶段反馈→自查自纠→核心讲评→变式训练→分层辅导→收尾作业），<15 分钟降级 3 阶段；
- 分层：优秀线/及格线默认 85%/60%（可配置），C 层附「结对帮扶+精讲题重做」任务与优先知识点；
- 全员高分（无必讲/应讲）自动切换为拔高引导题，不空转。

## 故障排查

| 现象 | 处理 |
|---|---|
| 退出码 2 + usage | 三类输入（--analysis/--qstats/--demo）至少给一个 |
| 「无法读取文件」 | 检查路径存在与编码（UTF-8） |
| 「JSON 格式错误」 | 文件为合法 JSON（可先 `python3 -m json.tool` 验证） |
| 「题目统计为空」 | questions 列表为空，检查表头与行 |
| CSV 表头不识别 | 检查列名是否含别名关键词（题号/id、得分率/p 等） |
| 分层名单为空 | 未提供成绩单时仅有分层标准；传 --students 或确认 analysis.students 非空 |

## 验证

`tests/run_self_test.py`（`python3` 直接跑）：30 条用例 + 断言全过（100%），覆盖常规主线、同义/别名/降级、组合覆盖、缺输入/坏文件、边界（全高分/全错/单题/无知识点/5 分钟课时）、异常数据（越界/非法/跳过）、确定性（两次哈希一致）、安全（XSS 双通道、CSV 公式注入、产物裁剪）。运行记录见 `tests/自测记录.md`。

## 安全说明

- 零第三方依赖、纯标准库、离线计算、确定性输出；
- HTML 全部 `html.escape` 转义并截断 100 字符；Markdown 单元清洗（竖线/尖括号全角化、控制字符清除）；CSV 对 `= + - @` 或制表符开头单元格加 `'` 前缀（防 Excel 公式注入）；
- 只写入 `--out-dir`，不执行任何用户可控文本。

## 限制

- 独立本地计算器：输入取自教务导出或手工整理文件，未直接对接具体系统（适配层留作扩展点）；
- 规则型建议基于教育测量常用约定，需教师结合学科经验把关；
- 不讲「怎么教」，只讲「教什么、讲多久、给谁补、怎么练」的备课骨架。
